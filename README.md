# Movie Watchlist

Movie Watchlist is a small Python application for organizing movies you want to watch.

Instead of using an online service, the application keeps a local collection of films, supports searching, statistics and simple recommendations based on ratings.

## Features

- Personal watchlist
- Search by title
- Filter by genre
- Rating support
- Watch status
- JSON export
- Collection statistics
